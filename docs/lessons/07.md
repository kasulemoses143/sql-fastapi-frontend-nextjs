## Vocabulary

JOIN: combine related rows. INNER JOIN: matching rows only. LEFT JOIN: keep all rows from the left table. Alias: a short table name used in a query.

## Explanation

An enrollment contains IDs, which are reliable references but poor display labels. A join matches those IDs to the corresponding names and course codes. The ON condition describes how records match; WHERE filters the resulting records.

INNER JOIN is useful for valid enrollments with existing parents. LEFT JOIN lets us include courses with no enrollments. Do not join student.id to course.id simply because both columns are named id: they identify different entities.

5. Save your SQL query file separately from the initial migration.

```sql
SELECT s.full_name, c.code, e.status
FROM enrollments e
JOIN students s ON s.id = e.student_id
JOIN courses c ON c.id = e.course_id
ORDER BY s.full_name, c.code;
SELECT c.code, e.id AS enrollment_id
FROM courses c LEFT JOIN enrollments e ON e.course_id = c.id
ORDER BY c.code, e.id;
```
