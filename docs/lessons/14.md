## Vocabulary

Type hint: expected value shape. Context manager: with-based cleanup. Generator: function yielding a value. Dependency lifetime: when a resource is available.

## Explanation

FastAPI uses Python annotations to interpret requests and document responses. A parameter annotated int is different from an untyped parameter. list[str] means a list of strings; a union such as int | None permits a missing value. Python annotations do not themselves validate every ordinary function call; FastAPI/Pydantic use them for validation at the web boundary.

A module is a Python file. Importing code runs top-level statements, which is why db.py loads configuration once. A with block guarantees cleanup when its block exits. get_session yields a Session to a request and closes it afterward. Never store a request's session in a global variable.

Synchronous SQLAlchemy calls use normal def routes here. Adding async def around blocking database calls does not make them nonblocking; an asynchronous driver/session design is a separate topic.

## Worked procedure

1. Save the standalone block below as resource_demo.py in your notes folder and run it with your virtual-environment Python.
2. Predict the order of output, including when the finally block runs.
3. Read get_session in db.py and compare its with/yield structure. Do not change it.
4. Explain what is imported by `from db import get_session` and why the launch directory matters.

```python
from contextlib import contextmanager

@contextmanager
def demo_resource():
    print('open')
    try:
        yield {'name': 'practice'}
    finally:
        print('close')

with demo_resource() as resource:
    print(resource['name'])
```
