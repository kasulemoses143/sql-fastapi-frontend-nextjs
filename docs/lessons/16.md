## Vocabulary

Path parameter: value in URL path. Query parameter: value after ?. Body: structured request payload. OpenAPI: machine-readable API contract.

## Explanation

The URL /practice/students/7?include_email=true has a path id and a query option. A JSON body is separate from both. Use path parameters to identify a resource, query parameters to control filtering/pagination, and bodies for structured create/update input.

HTTP statuses communicate meaning independently of the JSON body: 200 successful read/update, 201 created, 204 success without a body, 404 missing resource, 409 state conflict, 422 invalid request and 500 unexpected server error. A 200 containing an error-looking message is a poor substitute for a proper failure status.

This practice route has no database writes. The next capstone replacement removes it intentionally so temporary training endpoints do not become required application behavior.

```python
from fastapi import FastAPI
app = FastAPI(title='Student Course Enrollment API')

@app.get('/health')
def health():
    return {'status': 'ok'}

@app.get('/practice/students/{student_id}')
def practice_student(student_id: int, include_email: bool = False):
    return {'student_id': student_id, 'include_email': include_email}
```
