## Vocabulary

ORM: maps Python objects to relational records. Pydantic schema: validates API data. Dependency: resource supplied to a route. Commit: persist changes.

## Explanation

models.py describes existing SQL tables. It is not a second database. schemas.py describes permitted API inputs and outputs: StudentWrite has editable fields; StudentRead also exposes the generated id. The client does not choose the id. We use the same PostgreSQL tables created with SQL; the API does not create or reset them on startup.

Annotated[Session, Depends(get_session)] asks FastAPI for a request-scoped database session. The create route validates input, constructs a row, adds it, commits and refreshes it. refresh retrieves database-generated values. A duplicate constraint can fail at commit, so rollback is essential before reusing the session. A browser-side validation rule cannot replace server and database validation.

All table and request classes are supplied now so their relationships can be read together. Only student read/create routes are active in this checkpoint.

## Worked procedure

1. Create backend/models.py and backend/schemas.py using the complete files below. Read each class aloud: table mappings are different from request validation.

### Complete file backend/models.py

Create or replace `backend/models.py` inside **student-project**. This is the entire file for this stage.

```python
from datetime import date
from sqlalchemy import CheckConstraint, Date, ForeignKey, String, UniqueConstraint, func
from sqlalchemy.orm import Mapped, mapped_column
from db import Base

class Student(Base):
    __tablename__ = 'students'
    __table_args__ = (
        CheckConstraint("length(trim(full_name)) > 0", name='student_name_not_blank'),
    )
    id: Mapped[int] = mapped_column(primary_key=True)
    full_name: Mapped[str] = mapped_column(String(100))
    email: Mapped[str] = mapped_column(String(254), unique=True)

class Course(Base):
    __tablename__ = 'courses'
    __table_args__ = (
        CheckConstraint('credits BETWEEN 1 AND 6', name='credits_range'),
        CheckConstraint("length(trim(title)) > 0", name='course_title_not_blank'),
        CheckConstraint("length(trim(code)) > 0", name='course_code_not_blank'),
    )
    id: Mapped[int] = mapped_column(primary_key=True)
    code: Mapped[str] = mapped_column(String(20), unique=True)
    title: Mapped[str] = mapped_column(String(120))
    credits: Mapped[int]

class Enrollment(Base):
    __tablename__ = 'enrollments'
    __table_args__ = (
        UniqueConstraint('student_id', 'course_id', name='one_enrollment_per_pair'),
        CheckConstraint("status IN ('active', 'completed', 'withdrawn')", name='enrollment_status'),
    )
    id: Mapped[int] = mapped_column(primary_key=True)
    student_id: Mapped[int] = mapped_column(ForeignKey('students.id', ondelete='RESTRICT'), index=True)
    course_id: Mapped[int] = mapped_column(ForeignKey('courses.id', ondelete='RESTRICT'), index=True)
    enrolled_on: Mapped[date] = mapped_column(Date, server_default=func.current_date())
    status: Mapped[str] = mapped_column(String(20), server_default='active')
```

### Complete file backend/schemas.py

Create or replace `backend/schemas.py` inside **student-project**. This is the entire file for this stage.

```python
from datetime import date
from typing import Literal
from pydantic import BaseModel, ConfigDict, EmailStr, Field, field_validator

class InputModel(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True, extra='forbid')

class StudentWrite(InputModel):
    full_name: str = Field(min_length=1, max_length=100)
    email: EmailStr = Field(max_length=254)
    @field_validator('email', mode='after')
    @classmethod
    def normalize_email(cls, value):
        return str(value).lower()

class StudentRead(StudentWrite):
    model_config = ConfigDict(from_attributes=True)
    id: int

class CourseWrite(InputModel):
    code: str = Field(min_length=1, max_length=20)
    title: str = Field(min_length=1, max_length=120)
    credits: int = Field(ge=1, le=6, strict=True)
    @field_validator('code', mode='after')
    @classmethod
    def normalize_code(cls, value):
        return value.upper()

class CourseRead(CourseWrite):
    model_config = ConfigDict(from_attributes=True)
    id: int

class EnrollmentWrite(InputModel):
    student_id: int = Field(gt=0, strict=True)
    course_id: int = Field(gt=0, strict=True)

class EnrollmentUpdate(InputModel):
    status: Literal['active', 'completed', 'withdrawn']

class EnrollmentRead(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    id: int
    student_id: int
    course_id: int
    enrolled_on: date
    status: str

class EnrollmentDetail(EnrollmentRead):
    student_name: str
    course_code: str
    course_title: str
```

### Complete file backend/main.py

Create or replace `backend/main.py` inside **student-project**. This is the entire file for this stage.

```python
import os
from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException, Query, Response
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session
from db import get_session
from models import Student, Course, Enrollment
from schemas import (
    StudentWrite, StudentRead, CourseWrite, CourseRead,
    EnrollmentWrite, EnrollmentUpdate, EnrollmentRead, EnrollmentDetail,
)

app = FastAPI(title='Student Course Enrollment API', version='1.0.0')
origins = [x.strip() for x in os.getenv('CORS_ORIGINS', 'http://localhost:3000').split(',') if x.strip()]
app.add_middleware(
    CORSMiddleware, allow_origins=origins, allow_credentials=False,
    allow_methods=['GET', 'POST', 'PUT', 'PATCH', 'DELETE'],
    allow_headers=['Content-Type'],
)
SessionDep = Annotated[Session, Depends(get_session)]
Limit = Annotated[int, Query(ge=1, le=100)]
Offset = Annotated[int, Query(ge=0)]

def find_or_404(session, model, record_id):
    row = session.get(model, record_id)
    if row is None:
        raise HTTPException(404, 'Record not found')
    return row

def commit_or_conflict(session):
    try:
        session.commit()
    except IntegrityError:
        session.rollback()
        raise HTTPException(409, 'Conflict with an existing record or relationship')

@app.get('/health')
def health():
    return {'status': 'ok'}

@app.get('/students', response_model=list[StudentRead])
def list_students(session: SessionDep, limit: Limit = 100, offset: Offset = 0):
    return session.scalars(select(Student).order_by(Student.id).limit(limit).offset(offset)).all()

@app.post('/students', response_model=StudentRead, status_code=201)
def create_student(body: StudentWrite, session: SessionDep):
    row = Student(**body.model_dump())
    session.add(row)
    commit_or_conflict(session)
    session.refresh(row)
    return row

@app.get('/students/{record_id}', response_model=StudentRead)
def get_student(record_id: int, session: SessionDep):
    return find_or_404(session, Student, record_id)
```

## Independent practice

Trace one request from JSON → StudentWrite → Student → SQL INSERT → database row → StudentRead → JSON. What does rollback fix?

## Answer and reasoning

Try the task first. Validation checks shape and values before the handler runs. Student maps the row; commit persists it. refresh reads generated values. StudentRead defines the response. rollback clears a failed transaction; without it, later work in that session may fail.
