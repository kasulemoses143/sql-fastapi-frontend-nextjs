## Vocabulary

React component: function describing UI. JSX: markup syntax inside TypeScript. App Router: folders define routes. Layout: shared page wrapper.

## Explanation

A React component returns a description of the interface. JSX resembles HTML but uses TypeScript expressions inside braces and className instead of class. A component name starts with a capital letter. Lists need stable keys such as database ids.

Next.js provides routing and a build/deployment system around React. app/page.tsx renders the home route; app/students/page.tsx renders /students. app/layout.tsx wraps every page with shared navigation. Use Link for navigation.

App Router components are Server Components by default. Event handlers and useState need a Client Component, declared with 'use client' at the beginning of its file. That boundary is introduced next lesson. A browser cannot access a private database connection string.

## Worked procedure

1. Complete SETUP F. Copy the reference package.json and package-lock.json, postcss.config.mjs, tsconfig.json and next-env.d.ts and run npm ci inside student-project/frontend.
2. Create postcss.config.mjs and the Tailwind entry app/globals.css from the complete files below. The entry contains only the Tailwind import. Create app/layout.tsx and app/page.tsx using their complete blocks.
3. Create the three placeholder pages shown below so every navigation link has a working route.
4. Run npm run dev, open localhost:3000 and click each navigation link. Stop and restart the server once to understand which terminal owns it.
5. Read the component tree: RootLayout contains navigation and the current page passed as children.
