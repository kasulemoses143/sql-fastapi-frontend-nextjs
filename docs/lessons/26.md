## Vocabulary

Union: one of several types. Narrowing: refine a type after a runtime check. Number(): runtime numeric conversion. Assertion: compiler instruction, not conversion.

## Explanation

A function annotation documents what callers must provide and what is returned. A union such as string | number is useful when input can arrive in either form, but you must narrow or convert it before numeric logic.

A type assertion such as value as number does not convert a string at runtime. Number(value) does a conversion and may produce NaN; Number.isFinite and Number.isInteger are runtime checks. The API must validate again after receiving JSON.

Control flow uses if/else and loops. Keep business conditions readable and test the boundary values. A greater-than condition differs from greater-than-or-equal-to at the exact passing mark.

4. Rewrite the call loop with for...of and explain each variable's inferred type.

```typescript
function parseCredits(value:string | number):number {
  const credits = typeof value === 'number' ? value : Number(value);
  if (!Number.isInteger(credits) || credits < 1 || credits > 6) {
    throw new Error('Credits must be a whole number from 1 to 6.');
  }
  return credits;
}
for (const input of ['3', 4, 'bad']) {
  try {console.log(parseCredits(input));}
  catch (error) {console.log(error instanceof Error ? error.message : 'Unexpected error');}
}
```
