# Lesson 34 Typed components JSX and reusable props

## Learning objectives

Define component props; render expressions and conditional content; distinguish HTML from JSX syntax.

## Vocabulary

Component: function describing UI. Prop type: permitted parent-to-child input. JSX expression: JavaScript/TypeScript expression inside braces.

## Explanation

A TSX file combines typed code and JSX. Component names begin with a capital letter. Intrinsic HTML elements use lowercase. A prop type documents required values and catches misspelled properties at compile time.

Use braces for expressions, not whole statements. A conditional can use a ternary or an && expression. JSX uses className and htmlFor rather than the HTML attribute spellings. Return one outer element or a fragment.

A simple presentational component needs no useState and no client directive. Keep data flow visible: parent passes a value; child displays it. Interactivity and state belong in a Client Component, introduced next.

## Worked procedure

1. In student-project/frontend create components/StudentSummary.tsx with the first complete file below.
2. Replace app/students/page.tsx with the second file. Keep the dev server running.
3. Pass a different name and toggle enrolled. Observe the conditional text.
4. Intentionally pass enrolled='yes' and read the type error; restore a boolean before continuing.

Create components/StudentSummary.tsx:

```tsx
type Props = {name:string; enrolled:boolean};
export default function StudentSummary({name, enrolled}:Props) {
  return <article className="my-4 rounded-lg border border-slate-300 bg-white p-5"><h2 className="mb-3 text-xl font-semibold text-slate-900">{name}</h2><p>{enrolled ? 'Enrolled' : 'No enrollment yet'}</p></article>;
}
```

Replace app/students/page.tsx:

```tsx
import StudentSummary from '../../components/StudentSummary';
export default function StudentsPage() {
  return <><h1 className="mb-5 text-3xl font-bold tracking-tight text-slate-900">Students</h1><StudentSummary name="Amina Demo" enrolled={true} /></>;
}
```

## Independent practice

Add an optional courseCode prop with a fallback label. Why should the child not modify name?

## Answer and reasoning

Try the task first. Use courseCode?:string and render courseCode ?? "No course selected". Props belong to the caller; the child should communicate changes through callbacks rather than mutate input.
