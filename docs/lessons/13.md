## Vocabulary

Driver: database protocol library. Engine: connection factory. Session: ORM unit of work. Environment variable: configuration outside code.

## Explanation

psycopg speaks PostgreSQL's protocol. SQLAlchemy supplies SQL tools and ORM mapping. The engine is created once per application process. A session will be created and closed for each API request. It is not a global list and is not shared between requests.

The deployed API uses the provider's pooled endpoint. NullPool avoids accumulating another application-side connection pool inside each serverless process; the provider supplies pooling. This is a course design choice for small workloads. The direct endpoint is reserved for reviewed schema scripts.

SQLAlchemy URL schemes such as postgresql+psycopg select a Python driver. They are not valid raw psycopg connection schemes. db.py normalizes provider URLs safely without changing passwords or TLS parameters.

### Complete file backend/db.py

Create or replace `backend/db.py` inside **student-project**. This is the entire file for this stage.

```python
import os
from pathlib import Path
from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.engine import make_url
from sqlalchemy.orm import DeclarativeBase, Session
from sqlalchemy.pool import NullPool

load_dotenv(Path(__file__).with_name('.env'))

class Base(DeclarativeBase):
    pass

def database_url(raw):
    url = make_url(raw)
    if url.drivername in ('postgres', 'postgresql'):
        url = url.set(drivername='postgresql+psycopg')
    return url

engine = create_engine(
    database_url(os.environ['DATABASE_URL']),
    poolclass=NullPool,
    connect_args={'connect_timeout': 10},
)

def get_session():
    with Session(engine) as session:
        yield session
```

### Complete file backend/query_demo.py

Create or replace `backend/query_demo.py` inside **student-project**. This is the entire file for this stage.

```python
from sqlalchemy import text
from db import engine
# Bind data separately from SQL. Do not use f-strings to build queries.
with engine.connect() as connection:
    rows = connection.execute(
        text('SELECT id, full_name FROM students WHERE email = :email'),
        {'email': 'amina@example.com'},
    )
    for row in rows:
        print(dict(row._mapping))
```
