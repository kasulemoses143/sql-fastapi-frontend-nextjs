## Vocabulary

Literal union: specific allowed values. Optional property: may be absent. Intersection: combine object shapes. Readonly: disallow mutation through a type.

## Explanation

Types should express domain rules clearly. Status is not an arbitrary string: active, completed and withdrawn are the allowed values. A union catches spelling errors before the request is made. The backend still validates runtime input.

Optional properties may be undefined. Check their presence before using them. Avoid non-null assertions merely to silence errors: an exclamation mark does not create a missing value.

Spread creates shallow copies. When updating an array, map creates a new array and spread creates a new changed record. Nested objects would need copying at each changed level. This pattern prepares you for React state updates.

## Worked procedure

1. Run the complete example in the Playground. Inspect the literal union and readonly array.
2. Attempt to assign status='finished'. Read the type error and restore a permitted status.
3. Confirm the original row remains active while the new row is completed.
4. Add an optional note, then render a fallback using nullish coalescing.

```typescript
type Status = 'active' | 'completed' | 'withdrawn';
type Enrollment = {id:number; status:Status; note?:string};
const rows:ReadonlyArray<Enrollment> = [{id:1, status:'active'}];
const updated = rows.map(row => row.id === 1 ? {...row, status:'completed' as const} : row);
console.log(rows[0]?.status, updated[0]?.status);
console.log(updated[0]?.note ?? 'No note');
```

## Independent practice

What is the difference between `value || fallback` and `value ?? fallback` when value is 0?

## Answer and reasoning

Try the task first. || treats 0 as falsy and returns fallback. ?? returns fallback only for null or undefined, preserving legitimate zero values.
