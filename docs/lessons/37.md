## Vocabulary

FormEvent: React form event type. currentTarget: element handling the event. Controlled field: value and onChange tied to state.

## Explanation

An HTML input's value is a string, even for type=number. Convert deliberately before submitting numeric JSON. Empty strings must be treated carefully: Number('') returns zero, which may not be what the form means. Required controls and server validation are both necessary.

Type a submit handler with FormEvent<HTMLFormElement>. Event handlers are functions passed to React, not calls executed during render. Read e.target.value in the onChange callback and store it as state.

Do not clear the form before a network operation succeeds. Keeping input after failure lets the user fix a duplicate or validation problem. Disable repeated submission while a write is pending, and re-enable it in finally regardless of success.
