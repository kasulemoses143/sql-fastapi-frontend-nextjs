## Vocabulary

map: return one transformed result per item. filter: keep matching items. Spread: copy properties/elements. Module: exported reusable code. JSON: serialized data text.

## Explanation

A Python dictionary resembles a TypeScript object; a Python list resembles a TypeScript array. The languages have different syntax and runtime behavior. map produces a new array. filter selects items. Neither is a database query: in this lesson the data is already in browser memory.

JSON is a text format with double-quoted keys and no functions. JSON.stringify converts a TypeScript value to JSON text; JSON.parse converts JSON text into a value. fetch later serializes request bodies and parses responses.

Modules use export and import to share code between files. The Next.js build system will resolve those imports. A plain browser console does not automatically understand project-relative imports.

Use `Student[]` for an array of students and `type Student = {...}` for the record shape. Readonly arrays prevent accidental mutation through that reference. A type assertion does not convert or validate a value.

## Worked procedure

1. Run the complete Playground exercise below. Explain callback parameters and the new objects created with spread.
2. Filter students by name, then map to names. Record the original array to check it has not changed.
3. Use JSON.stringify and JSON.parse. Compare typeof for the object and the serialized string.
4. On paper, split a formatStudent function into a module using `export function formatStudent(s) {...}` and an importer using `import {formatStudent} from './format'`.
5. Explain named vs default exports using a small example; Next page components will use default exports.

```typescript
type Student = {id:number; full_name:string};
const students:Student[] = [{id:1, full_name:'Amina'}, {id:2, full_name:'Brian'}];
const names = students.map(s => s.full_name);
const updated = students.map(s => s.id === 1 ? {...s, full_name:'Amina Demo'} : s);
const text = JSON.stringify(students);
const restored = JSON.parse(text);
console.log(names, updated, students, typeof text, restored);
```

## Independent practice

Use filter to remove id=1 without changing the original array. What does a missing object property evaluate to?

## Answer and reasoning

Try the task first. `students.filter(s => s.id !== 1)` creates a new array excluding that record. A missing property evaluates to undefined. Do not confuse an absent property with a database NULL.
